# Primitive DB

Консольное приложение, имитирующее работу с простой базой данных.
Позволяет создавать, просматривать и удалять таблицы. Описание таблиц
хранится в JSON-файле.

## Установка

Для разработки:

```bash
uv sync
```

Установка как консольной команды:

```bash
uv build
uv tool install dist/primitive_db-0.3.0-py3-none-any.whl
```

## Запуск

После установки:

```bash
database
```

Из папки проекта без установки:

```bash
uv run database
```

## Управление таблицами

Описание таблиц (имена таблиц, их столбцы и типы) хранится в файле
`db_meta.json`. Файл создаётся в текущей папке при создании первой таблицы,
поэтому программу нужно запускать из одной и той же папки.

### Команды

| Команда | Описание |
|---|---|
| `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` | создать таблицу |
| `list_tables` | показать список всех таблиц |
| `drop_table <имя_таблицы>` | удалить таблицу |
| `help` | справочная информация |
| `exit` | выход из программы |

Поддерживаемые типы данных: `int`, `str`, `bool`.

Столбец `ID:int` добавляется в начало таблицы автоматически.

Если в имени таблицы или столбца есть пробел, его нужно взять в кавычки:
`create_table "my table" "full name:str"`.

### Пример использования

```
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool
>>>Введите команду: create_table users name:str
Ошибка: Таблица "users" уже существует.
>>>Введите команду: list_tables
- users
>>>Введите команду: drop_table users
Таблица "users" успешно удалена.
>>>Введите команду: drop_table products
Ошибка: Таблица "products" не существует.
>>>Введите команду: exit
```

При ошибке в команде программа сообщает о ней и снова ждёт ввода:

```
>>>Введите команду: create_table orders price:float
Некорректное значение: price:float. Попробуйте снова.
>>>Введите команду: select
Функции select нет. Попробуйте снова.
```
